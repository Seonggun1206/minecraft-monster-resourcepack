# Goblin Scout source

This folder contains the editable Blockbench model, texture atlas, and RP Engine definitions for the Goblin Scout prototype.

- Base entity: Vindicator, so the custom goblin does not use zombie villager infection behavior.
- Model: `goblin_scout.bbmodel`.
- Texture: `goblin_scout_atlas.png`.
- Animation clips: idle, walk, run, attack, hurt, death.
- The server-side Skript behavior is maintained in the Paper server's plugin folder, not in this resource-pack repository.
- No custom drops or loot tables are defined.

The model is packed in the root `MonsterPack.zip`. Appearance and animation still need in-game verification after players receive the pack.
